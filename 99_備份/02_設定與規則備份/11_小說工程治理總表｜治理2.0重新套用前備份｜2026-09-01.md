# 01｜Revision Levels

01｜REVISION LEVELS

原則：未指定層級時，以完成作者要求所需的最低層級施工。若途中發現必須升級，停止該部分；涉及 R4 時必須有作者明確決定。

R0｜COPY／FORMAT

允許：錯字、標點、明顯語病、格式一致性。

禁止：改資訊、事件、人物意圖、語義、章級節奏。

備份：通常不需新增快照。

R1｜PROSE EDIT

允許：句法、段落節奏、中文母語化、反 AI 味、局部台詞自然化。

禁止：新增／刪除事件、改 Knowledge、資訊揭露時點、場景 CHANGE、關係狀態、Canon。

備份：大範圍整章 prose pass 依里程碑制保留一份，不為每句建快照。

R2｜SCENE EDIT

允許：重排同一場景 beats、互動、資訊出場順序，補／刪有功能的局部互動。

必須保留：章級目的、鎖定事件、Knowledge 邊界、章末 State、HARD dependency。

一旦改變上述任一項，升格 R3／R4。

R3｜CHAPTER REWRITE

允許：整章重建、場景拆併、敘述順序大改。

必須保留：現行 Canon、作者已鎖章節目的、必要事件、章末狀態與後續 HARD dependency。

施工前：一份正文里程碑備份＋核對 State／Knowledge／Dependency。

施工後：重做整章 Acceptance Tests、冷讀與 State Diff。

R4｜STRUCTURAL／CANON REVISION

範圍：改事件、章序、角色弧、關係節點、世界規則、資訊真相、術語階級、既有 HARD dependency。

前提：作者明確授權／決定。作者只指出問題但尚未決定答案時，不自行選答案。

施工：先改最高權威來源，再同步 09／11／正文；建立里程碑備份；重大治理或 Canon 變更記 00A。

快速判定

「這句很 AI」→ R1，並掃同類生成模式。

「這場戲不順，但事件別動」→ R2。

「整章重寫，事件／章末狀態別動」→ R3。

「相遇方式／年齡／關係節點／世界規則要改」→ R4。

[ ] 刪／改事件後，HARD dependency 仍成立。

F｜SCENE

[ ] 重要事件真的演出，不以摘要替代。

[ ] 場景不是只為介紹設定。

G｜DIALOGUE

[ ] 沒有一句台詞朗讀動機＋情緒＋價值觀＋本章主題。

[ ] 潛台詞沒有被角色解說給讀者。

[ ] 允許停頓、答非所問、改口、拒答，但沒有把其中一種做成固定招牌。

H｜PROSE／ANTI-AI

[ ] 沒有「症狀／感官 A→B→C → 結論」的清單式流水帳。

[ ] 沒有「場景演出 → 抽象解釋 → 段尾總結」三連。

[ ] 沒有大量一句一段、短句階梯、固定微表情、固定段尾餘韻。

[ ] 泛用比喻／彷彿／似乎／像是只有在增加具體資訊時保留。

[ ] \`不是A而是B／真正的／從來都不是／他終於明白\` 等概念模板沒有形成慣性。

[ ] 角色名替換後若可原封不動塞進大量 AI 小說，優先重寫。

[ ] 景物由 POV 當下注意力選擇，不做無目的攝影機掃描。

[ ] 身體反應直接、具體；不靠萬用「胸口像被壓住／空氣凝固／聲音像很遠」。

[ ] 前面已演出的事沒有再替讀者重述。

I｜READER KNOWLEDGE／RELATIONSHIP

[ ] 讀者知道的資訊不超過作品實際揭露。

[ ] 懸念是有意識保留，不是 POV 人為藏資訊。

[ ] 女主有自身目的與彼此關係；亞德里安不是所有領域自動隊長。

[ ] 信任、依附、親密與選擇不因單一場景一步到位。

J｜ERA／TERM／FORMAT／LENGTH

[ ] 異世界一般治療者＝牧師；神官只用較高階宗教職位；現代段可用醫院／醫師／急診。

[ ] 稱謂、階級、年齡、職業、時代語感正確。

[ ] 章長服從作者最新指示與現行 09，不靠灌水／硬砍達標。
