# 01｜Revision Levels

01｜REVISION LEVELS

原則：未指定層級時，以完成作者要求所需的最低層級施工若途中發現必須升級，停止該部分；涉及 R4 時必須有作者明確決定

R0｜COPY／FORMAT

允許：錯字、標點、明顯語病、格式一致性

禁止：改資訊、事件、人物意圖、語義、章級節奏

備份：通常不需新增快照

R1｜PROSE EDIT

允許：句法、段落節奏、中文母語化、反 AI 味、局部台詞自然化

禁止：新增／刪除事件、改 Knowledge、資訊揭露時點、場景 CHANGE、關係狀態、Canon

備份：大範圍整章 prose pass 依里程碑制保留一份，不為每句建快照

R2｜SCENE EDIT

允許：重排同一場景 beats、互動、資訊出場順序，補／刪有功能的局部互動

必須保留：章級目的、鎖定事件、Knowledge 邊界、章末 State、HARD dependency

一旦改變上述任一項，升格 R3／R4

R3｜CHAPTER REWRITE

允許：整章重建、場景拆併、敘述順序大改

必須保留：現行 Canon、作者已鎖章節目的、必要事件、章末狀態與後續 HARD dependency

施工前：一份正文里程碑備份＋核對 State／Knowledge／Dependency

施工後：重做整章 Acceptance Tests、冷讀與 State Diff

R4｜STRUCTURAL／CANON REVISION

範圍：改事件、章序、角色弧、關係節點、世界規則、資訊真相、術語階級、既有 HARD dependency

前提：作者明確授權／決定作者只指出問題但尚未決定答案時，不自行選答案

施工：先改最高權威來源，再同步 09／11／正文；建立里程碑備份；重大治理或 Canon 變更記 00A

快速判定

「這句很 AI」→ R1，並掃同類生成模式

「這場戲不順，但事件別動」→ R2

「整章重寫，事件／章末狀態別動」→ R3

「相遇方式／年齡／關係節點／世界規則要改」→ R4

# 02｜Acceptance Tests

02｜ACCEPTANCE TESTS｜GOVERNANCE 2.0

用途：這一頁只在 QA MODE 使用，不得整頁直接交給主筆起稿結果使用 PASS／FAIL／NEEDS AUTHOR關鍵字零命中不等於 PASS；STYLE／AI 類問題以模式判定，不以單句形式判死刑

A｜HARD GATE｜AUTHORITY／CANON

[ ] 沒從 LEGACY、備份、原型或模型常識補回設定

[ ] 所有新增事實可追到現行權威；無來源則維持 TBD

[ ] 正文沒有反向改寫人物 Bible、關係矩陣或世界規則

[ ] 需要作者決定的 Canon／制度／動機／真相沒有被模型自行補成答案

B｜HARD GATE｜POV／KNOWLEDGE

[ ] 一個完整場景只在一名焦點角色的認知內

[ ] 每項角色資訊有取得來源／記憶依據

[ ] KNOWS／BELIEVES／SUSPECTS／UNKNOWN 沒混寫

[ ] 沒共享作者視角、讀心或提前知道未揭露真相

[ ] 第一人稱沒有故意 withholding 自己已知且正在想的資訊

C｜HARD GATE｜CAUSALITY／INFO

[ ] 重要後果有足夠前提，但正文不必替讀者逐條說明因果

[ ] \`又、再次、仍然、果然、照例、和平常一樣\` 等前情詞已有依據

[ ] 刪／改事件後，HARD dependency 仍成立

[ ] 不知道的事保持不知道；「目前沒有」沒有偷寫成永久真相

D｜HARD GATE｜STATE CONTINUITY

[ ] 時間、年齡、地點連續

[ ] 傷勢、體力、魔力、限制連續

[ ] 重要物品持有者與去向連續

[ ] 關係沒有無前提跳級；前章造成的狀態沒有無原因歸零

[ ] 允許心理狀態停滯、反覆或暫時倒退；State Diff 記的是結果，不是正文必須逐步履約的路線

E｜HARD GATE｜ERA／TERM／FORMAT

[ ] 異世界一般治療者＝牧師；神官只用較高階宗教職位；現代段可用醫院／醫師／急診

[ ] 稱謂、階級、年齡、職業、時代語感正確

[ ] 章長服從作者最新指示與現行 09，不靠灌水／硬砍達標

[ ] Google Docs 原生 Tabs、章名、空行、標點、換行沒被誤傷

F｜CHARACTER／VOICE｜QUALITY GATE

[ ] WANT／恐懼／盲點與行為一致，不為推劇情降智

[ ] 遮掉姓名後，主要角色的注意力、思考節奏、句長、迴避方式與直接程度仍可分辨

[ ] 不同 POV 沒有共用「觀察 → 分析 → 結論」同一種 reasoning 節奏

[ ] 亞德里安可以理性，但不是每次都當場完成自我診斷；允許先反應、晚點才理解

[ ] 幼年莉諾兒不是成人分析師；想法優先貼著具體人、物、距離、身體與眼前需求

[ ] 克蕾西雅不是全知情報女王；瑟拉菲娜不是說教機器；艾琳娜不是天然呆／讀心者／衝就一定對

[ ] 角色各自有不同的誤判方式；不是所有人都用同一套作者邏輯得出正確答案

G｜SCENE PURPOSE｜QUALITY GATE

[ ] 場景有存在理由，但不強制每場都有 TURN／CHANGE

[ ] 若 CHANGE＝NONE，仍能回答「刪掉這場，讀者會失去什麼？」

[ ] 有效理由可包含：事件、資訊、關係質感、角色習慣、生活感、情緒餘波、恢復過程、對比或下一場的心理準備

[ ] 重要事件真的演出，不以一句摘要替代

[ ] 場景不是純設定簡報；人物正在做事、生活、恢復、等待、犯錯或與人相處

[ ] 允許普通、沒有大結果的小事存在，不要求每個細節都有伏筆或 payoff

H｜DIALOGUE｜PATTERN RISK

[ ] 真人在這個身分、年齡、身體狀態與場合會這樣說

[ ] 沒有反覆用一句台詞朗讀動機＋情緒＋價值觀＋本章主題

[ ] 潛台詞沒有被角色習慣性解說給讀者

[ ] 允許停頓、答非所問、改口、拒答、說錯重點，但沒有把其中一種做成固定招牌

[ ] 對話可以有寒暄、瑣碎、沒得到答案或沒有立刻推進主線的部分，只要符合人物與場合

I｜PROSE／ANTI-AI｜PATTERN RISK

單次出現不自動 FAIL；只有形成生成慣性、角色同質化或實際降低閱讀品質時才判錯

[ ] 沒有反覆出現「症狀／感官 A→B→C → 結論」的清單式流水帳

[ ] 沒有習慣性「場景演出 → 抽象解釋 → 段尾總結」三連

[ ] 沒有大量一句一段、短句階梯、固定微表情、固定段尾餘韻

[ ] 比喻、彷彿、似乎、像是若出現，符合 POV 聲音並真的增加質感／資訊；不是因形式本身被禁

[ ] \`不是A而是B／真正的／從來都不是／他終於明白\` 等概念模板沒有形成慣性

[ ] 景物與感官由 POV 當下注意力選擇；不做無目的攝影機掃描，也不因怕攝影機感而把所有環境刪光

[ ] 身體反應有重量與具體感；不是症狀報表，也不是萬用氣氛比喻

[ ] 前面已演出的事沒有習慣性再替讀者重述

J｜NON-LINEAR HUMAN RESPONSE

[ ] 角色可以知道某件事「比較安全」，但身體／習慣／情緒沒有被迫同步更新

[ ] 信任、創傷、依附、好感與戒心不是單調遞增條

[ ] 允許今天可以、明天又不行；進兩步退一步；同時存在矛盾反應

[ ] 重要理解可以延後到之後才出現，也可以只表現在行為改變而沒有抽象心得

[ ] 莉諾兒 Ch6–Ch7 類場景尤其不得寫成「取得安全證據 A → 信任 +1 → B → +1」

K｜OVER-COMPLIANCE FORENSICS

任一項大量成立，即使 Canon／POV 全 PASS，也視為品質 FAIL，需要回到場景層重寫，而不是再加禁詞

[ ] 每一段是否都看得出正在完成哪條設定／章綱條目？

[ ] 場景是否每一個都太有效率，沒有呼吸、岔路、無結果的小事？

[ ] 角色是否每次都即時而正確地理解自己的情緒、錯誤與社會意義？

[ ] 不同角色是否都以相同句法、相同冷靜程度、相同邏輯密度敘事？

[ ] 心理變化是否和 State Diff／Dependency Graph 的順序一模一樣？

[ ] 是否因為害怕 AI 比喻／修辭，最後只剩「走、看、問、坐、拿、回答」的動作報告？

[ ] 是否所有細節都有明顯任務功能，以致人物像在測試案例裡活動？

[ ] 是否能看見 Scene Card／Knowledge Ledger／Acceptance Tests 的欄位直接滲進正文？

L｜READER KNOWLEDGE／RELATIONSHIP

[ ] 讀者知道的資訊不超過作品實際揭露

[ ] 懸念是有意識保留，不是 POV 人為藏資訊

[ ] 關係進展符合各組獨特核心，不共用「發現他其實很溫柔」

[ ] 女主有自身目的與彼此關係；亞德里安不是所有領域自動隊長

[ ] 信任、依附、親密與選擇不因單一場景一步到位

M｜FINAL COLD READ

最後把規則表放到一邊，從讀者角度連續讀完整章：

[ ] 哪裡一眼像 AI 在交作業？

[ ] 哪裡角色像在替作者整理邏輯？

[ ] 哪裡太乾、太規矩、太平均？

[ ] 哪裡明明完全合理，卻沒有任何想繼續讀的慾望？

[ ] 哪個細節、反應或對話只有這個角色會有？

Hard Gate：A–E 與明確 OOC／Canonical contradiction 成立＝FAIL；需要作者決定＝NEEDS AUTHORF–M 是品質驗收，按模式與整體閱讀效果判定，不以單一關鍵字定罪

# 03｜Voice Fingerprints

03｜VOICE FINGERPRINTS｜GOVERNANCE 2.0

用途：以下只壓縮現行人物 Bible、關係 Canon 與已通過正文，不新增人格 Canon這頁不是口癖表，而是用來讓不同 POV 擁有不同的注意力、認知節奏、誤判方式與情緒延遲主筆起稿只取當前 POV 的必要片段

亞德里安・梵恩

ATTENTION：問題、矛盾、因果、成本、可用資訊、實際需求

PUBLIC：簡短、禮貌、資訊夠就停；低社交需求不等於刻意冷

FAMILIAR：稍鬆、實際問題多、偶有乾式吐槽與 ACG 聯想

EXCITED：問題變多、注意力集中，不突然熱血大喊

COGNITIVE TEXTURE：理性是處理問題的方法，不是每次都在腦內完成報告事情發生時可以先尷尬、煩、想逃、被吸引、搞錯重點；理解可以晚幾分鐘、晚一晚，甚至只表現在下次行為改變

ERROR BIAS：容易把「自己撐得住」當成成本不高；容易太早把事情當成可以解決的問題；跨文化時能觀察到異常，但原因可能猜錯

EMOTION：通常知道自己在高興、生氣、尷尬、害怕或喜歡；不需要把每個情緒拆成原因分析

PROSE TEXTURE：可以有直接念頭、普通吐槽、突然被小事吸走注意力；不要每段都觀察→分析→結論

AVOID：高冷霸總、無情計算機、完整心理報告、帥氣反殺台詞、永遠推理命中

克蕾西雅

ATTENTION：人際變化、資訊來源、利益、前後不一致、沒說出口的部分

PUBLIC：得體、句子較完整、會柔和拒絕與轉題

PRIVATE：更短、更直接，會嫌麻煩；熟人安全時才偶爾逗人

COGNITIVE TEXTURE：會記住異常與來源，但不需要當場把每個人整理成完整人物檔某些疑點可以先擱著，之後因另一條資訊才重新想起

ERROR BIAS：資訊不完整時可能過度解讀前後落差；網絡能增加線索，不等於能直接取得動機或真相

PROSE TEXTURE：注意人和資訊，但仍會被禮貌、疲勞、工作瑣事與私人偏好打斷

AVOID：全知情報女王、永久謎語人、每場都撩、看人＝讀心

CURRENT TEXT：截至第七章尚未登場

瑟拉菲娜

ATTENTION：傷病、程序、責任、選擇權、倫理後果、誰會受影響

PUBLIC：清楚、穩定、有禮；不需要每句莊重或像布道
