# ADR-0003｜序章七章因果重建與過渡弧

STATUS：accepted（追記已合併的既有決定，不是新授權）
DATE：2026-11-25
DECIDERS：作者（2026-11-22「先寫看看寫完再對一次規則」；已合併 PR #47）
supersedes：ADR-0002 的六章結構與章別索引；其餘敘事與西幻器具決定仍有效。

## Context

PR #44 採六章重構；其後 [PR #47](https://github.com/waydefu/2026novel/pull/47) 已將核心序章改為七章，現行正文、09 大綱、11 與 v6 Canon 契約均以七章為基準。ADR-0002 尚記錄六章，可能讓代理誤讀當前結構。

## Decision

- 將現代死亡與七歲甦醒分為 Ch1、Ch2；屠村救援為 Ch5，首次揭露莉諾兒姓名及年齡為 Ch6，自行暫留、通用語認字與王都學院預先通知為 Ch7。
- 核心序章七章之後，09-P08 是尚未施工的過渡弧，可依大綱拆成 P08A/P08B，不得提前寫成已發生事件；第一篇 A1-01～A1-08 保留既有大綱。
- 保留全書第三人稱限知多 POV、西幻器具與既有 Canon。未決事件、身分與制度仍需作者決定。

## Consequences

以現行 09、11、Canon v6（CC-019～026）與 PR #47 為章別依據。ADR-0002 歷史內容保留，只調整生命週期 metadata，避免把已被取代的六章索引當現行規則。

## Alternatives considered

不改舊 ADR 的歷史正文；不重做已合併的 R4 決策、不新增事件。

## Verification

已閱讀 main 七章標題、09、11 與 PR #47 合併紀錄；本次僅治理追記，未修改正文、Canon 或 TBD。CI 待本 PR 實際執行。
