# 盲讀比較｜2026-10-22｜Ch8「她先認字」

依 `governance/quality-evaluation.md` §第二層執行。這是該協議的**第一次實測**。

## 方法

| 項目 | 設定 |
|---|---|
| 稿件甲 | 新寫的 Ch8「她先認字」全章（1,660 字） |
| 稿件乙 | 現行 Ch4「只是多試一次」節選（前 1,612 字） |
| 處理 | 兩份都去掉章名標題與任何可辨識標記，長度對齊（差 48 字） |
| 評閱者 | 一個**無上下文**的子代理（不知道哪份較新、不知道兩份來自哪裡、不知道設定） |
| 維度 | 閱讀流暢度／角色辨識度／場景生命力／情緒可信度／敘事吸引力，各 1–5 分 |
| 限制 | 單一評閱者、單一組對照；不足以推論整體品質，只能當方向訊號 |

## 評閱者指出、甲（本章）的問題：4 處

| # | 問題 | 原文 | 處置 |
|---|---|---|---|
| 1 | 成長史摘要腔：三段式把數月變化一次講完，敘述頓住 | 「剛來的時候她只待在房間裡，後來肯下樓，再後來每天傍晚都會過去坐一會兒」 | v4 刪除，改成「這個時間，莉諾兒通常已經坐在廚房那張凳子上」——只留他的預期，不給總結 |
| 2 | 把小動作解讀成主題 | 「腳步也沒有因為被少爺問話而慢下來」 | v4 改成「侍女端著盤子走了」 |
| 3 | 把世界運作規則講白 | 「沒有人再為這件事專門停下來，也沒有人覺得需要回報」 | v4 整句刪除 |
| 4 | 替讀者解釋她的行為動機 | 「那是她自己養成的習慣。」 | v4 刪除 |

**這 4 處詞庫全部抓不到**（`prose_lexicon.py` 本章命中 0），因為它們不是用詞問題，是敘事層的「演出完再補一句解釋」。這是本次盲讀最重要的方法論結果：**機械詞庫對敘事層解釋完全失明**，只有人讀才抓得到。

## 評閱者指出、乙（Ch4 節選，已定稿章）的問題

這些**不是**本次改動範圍，但已定稿的第四章存在同類問題，列入後續 backlog：

- 現代網文式自嘲與西幻慢熱語調打架：「作品裡通常會更誇張。」
- 機械編號平行句：「第一次…第二次…第三次…」連用兩次
- 老師替讀者總結原理：「只代表通過得多，不代表控制得好。」
- 少年替世界下判語：「好吧，魔法比遊戲技能麻煩多了，也有趣多了。」
- 清單式並列開場：「一塊巴掌大的黑色圓板、一枚比手腕稍寬的銀環……」
- 缺前文錨點：「臥床那幾天就看過它們。」

## 評閱者認為「只有這個角色才會有」的細節（甲）

## 返工次數

**3 次**（v1 → v2 → v3 → v4）。

| 輪次 | 觸發 | 內容 |
|---|---|---|
| v1 → v2 | 自冷讀 | 刪作者解說句、修正婦人對男孩用「妳」、以炭筆動作取代抽象比喻 |
| v2 → v3 | 自冷讀（密度與時間流逝） | 補「僕人已自然稱莉諾兒小姐」、補「明天要學『澤』」 |
| v3 → v4 | **盲讀** | 刪 4 處敘事層解釋（見上表） |

第一輪與第二輪都由自冷讀抓到；第三輪才由獨立評閱者抓到新的類型（敘事層解釋），而機械掃描始終 0 命中。結論：**自冷讀不足以覆蓋敘事層解釋，盲讀是必要的一層**。
