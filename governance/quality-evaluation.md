# 作品品質驗證｜盲讀比較與誠實指標

STATUS：ACTIVE（不阻擋 CI）｜更新：2026-10-22

## 前提

工具能證明的是「格式、連續性、規則有沒有被執行」，**不能**證明「這一章好不好看」。

中文對照語料研究（例如 283 萬字／629 篇那一套）能排除錯誤的去 AI 味規則，但它衡量的是**特徵出現頻率**，不是文學品質。近期研究（例：*Beyond Correctness: Evaluating Subjective Writing Preferences Across Cultures*，600 組中文寫作偏好比較）也指出：只用常見評分方式，很難可靠判斷主觀寫作品質。

因此本專案把品質驗證分成兩層：**可機檢的**（CI 擋）與**只能人讀的**（盲讀，不擋）。

## 第一層：可機檢（CI 阻擋）

| 面向 | 工具 | 判定 |
|---|---|---|
| 格式與命名 | `scan_hard_gate.py` | HARD GATE，違規即紅 |
| 既存事實 | `canon_contract.py` | 契約違規即紅 |
| 規則體量 | `check_rule_budget.py` | 超標即紅 |
| 規則同步 | `sync_agent_rules.py --check` | 漂移即紅 |
| 詞庫未偷改 | `prose_lexicon.py --check-lock` | 雜湊不符即紅 |
| 修稿層級 | `check_revision_gate.py` | 違規即紅 |
| Skill 規格 | `validate_skills.py` | 不合規格即紅 |
| 文風候選 | `prose_lexicon.py`／`prose_rhythm.py`／`style_profile.py` | **只報告**，人工判讀 |

## 第二層：盲讀比較（不阻擋）

用途：回答「這次改稿之後，讀起來是不是真的比較好」。

### 做法

1. 同一場景卡、同一份 Canon，產生兩份稿：A＝改寫前，B＝改寫後。
2. 評讀者**不知道**哪一份是哪一版（去標籤、隨機排序）。
3. 每份只讀一次，不做對照評論。
4. 五個維度各自打分或選擇：

| # | 維度 | 問題 |
|---|---|---|
| 1 | 閱讀流暢度 | 哪一版比較自然，不需要反覆重讀？ |
| 2 | 角色辨識度 | 遮住姓名後，還看得出角色說話與思考的差異嗎？ |
| 3 | 場景生命力 | 人物有在生活與行動，還是只在完成場景卡？ |
| 4 | 情緒可信度 | 反應是否符合當下處境，而不是套用心理進度表？ |
| 5 | 敘事吸引力 | 哪一版更讓人想繼續讀下一段？ |

5. 記錄：偏好、理由、**誤判**（選了但事後覺得另一版較好）、返工次數。

### 場景取樣

至少三種性質不同的場景，因為它們的寫作需求不同，不能用同一種句長或對話比例評分：

1. **一般生活場景**（吃飯、找東西、走路）— 考的是生活感與細節密度。
2. **情緒或關係變化場景**（信任、退縮、誤會）— 考的是反應可信度與進退兩步。
3. **事件推進與資訊密集場景**（救援、調查）— 考的是因果清晰度與節奏。

### 使用限制

- 盲讀**不得**成為 CI 門檻。單一模型的評分不決定作品好壞。
- 樣本數少，結果只能當**方向訊號**，不能當統計結論。
- 從局部場景先做，不要一開始重生成整章。
- 若兩版差異不明顯，記錄「無明顯差異」——這本身就是結果，不要硬選。

## 第三層：誠實的誤報率

社群常用的門檻是「正常文本誤改率 < 10%」。那需要明確分母：

```
誤改率 = 被工具標記、但人工判定應保留的段落數 ÷ 被工具掃過的正常段落總數
```

- **分子**：人工逐條判讀後判定為誤報（保留）的命中數。
- **分母**：同一工具在正常文本上掃過的段落總數（不是命中數）。
- 目前 `evals/run_evals.py` 用的是「正樣本候選數 ≤ 2」的**代理指標**，**不等於**誤改率 < 10%。要真正驗證，需要一份人工標註過的正常段落集（每段標 known-good / known-bad）。

目前的做法：正樣本 fixture 控制在 2 筆候選以內，負樣本必須命中多組；這是**保守起步**，不是誤改率驗證。要升級成真誤改率，需建立標註集。

## 與 P08 的關係

P08（留下以後）是治理系統的第一個實戰驗證。品質驗證應在 P08 施工前後各做一次盲讀比較，而不是等到整本寫完才回頭看。
