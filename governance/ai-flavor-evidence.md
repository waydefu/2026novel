# 中文去 AI 味：證據分級與本專案裁決

STATUS：ACTIVE｜更新：2026-10-22

本檔是「哪些中文寫作特徵真的能判別 AI 味、哪些只是流行清單」的依據。**掃描器與人工判讀都以此為準**。本檔沒有 Canon 權力，只約束工具設計與 QA 判讀。

## 1. 什麼不成立（不得作為改寫依據）

來源：`lieflat-less-ai-tone` RESEARCH.md（283 萬字、629 篇對照語料）。R = AI 使用率 ÷ 人類使用率；R < 1 表示人類用得更多。

| 特徵 | R | 裁決 |
|---|---|---|
| 句長均勻度 | 0.87 | **不成立**。不得為了製造節奏而調句長、拆段落。 |
| 相鄰句長差 | 1.00 | **不成立**。 |
| 段長均勻度 | 0.94 | **不成立**。與社群 `aeopress/novel-skills` 的「段落 CV<0.15 警示」衝突，本專案採**僅提示、不設限**。 |
| 比喻（任何） | 0.42 | **不成立**。人類用比喻是 AI 的 2.4 倍，獨立成段 8 倍。只有「理想化擬人喻體」（R=7.3）才是真特徵。 |
| 設問句 | 0.05 | **不成立**。人類是 AI 的 17 倍；刪設問會更像 AI。 |
| 句內排比 | 0.61 | **不成立**。只有句間重複才成立。 |
| 被動句 | 0.70 | **不成立**。能表達受事與責任時保留。 |
| 動詞名詞化 | 0.52 | **不成立**。術語不要拆。 |
| 單字虛詞（就／很／了） | 0.45 | 方向是「補」不是「刪」，且無法驗收 → 棄用。 |
| 口語連接詞 | 0.26 | 同上，棄用。 |
| 正文「首先／其次／最後」 | 2.00（句首） | 區分：**小標題編號**成立（R=3.1）要處理；**正文過渡詞**實測無差異 → 本專案只在「硬拆三點且三點長度幾乎相等」時才動。 |
| 冒號（句中總說分說） | 1.66 | 人類組間極差 6.6 倍，無法判斷來源 → 不改。 |
| 破折號 | 3.0（模型間極差 40 倍） | 不採通用門檻；本專案改用自有正負樣本量測（`tools/style_profile.py`）。 |

工具層面的落實：`tools/prose_lexicon.py` 的 `--not-evidence` 會列出以上項目；`tools/style_profile.py` 把非判據項目標成「(非判據)」。

## 3. 本專案的量測基準

用**自己的正負樣本**校準，不用通用門檻：

| 樣本 | 來源 | 用途 |
|---|---|---|
| 正樣本 | `evals/fixtures/pass_human_prose.md`（現行第三版節錄） | 假陽性控制 |
| 負樣本 | `evals/fixtures/pattern_ai_flavor.md`（舊第二版節錄，PLOT RESET 前） | 真陽性控制 |

實測差異（每千字）：空泛評價形容 0 → 12.2；作者解說句 0 → 6.1；抽象名詞 0 → 3.1；首先其次最後 3.0 → 9.2；冒號 3.0 → 6.1。

差異明顯的項目進 `governance/style-profile.json` 的 bands；差異不明顯的不設限。

## 4. 判定門檻（借用社群發布標準）

借用 `MrGeDiao/shuorenhua` 的做法：資訊硬失敗＝0；**正常文本誤改率 < 10%**；正向樣本多數有可見收益。

本專案對應：`evals/run_evals.py` 必須證明

- 正樣本上的詞庫候選數 ≤ 預算（誤改率控制）；
- 負樣本上必須命中多個群組（真陽性）；
- 契約違規樣本必須紅、合規樣本必須綠；
- 詞庫 hash 與 `governance/lexicon.lock` 一致（尺子沒被偷偷放寬）。

## 5. 三層防護（工具命中只是候選）

1. frontmatter 的 `description` 明寫：機械掃描結果一律視為待人工判讀的線索，不得單獨作為改寫依據；零命中不等於通過。
2. 內文設「證據等級」節，列出「機器能算的／只能算字面形態的／算不出的」，並把 §1 的表列為硬約束。
3. 輸出格式強制把「機械線索（嫌疑）」與「語意判讀與處置」分成兩區，且「保留理由」欄必填。

## 6. 不做的事

- 不做 AI 偵測繞過。偵測器不可靠（RAID benchmark；對非母語寫作者的偏誤研究），偵測分數不是目標。
- 不用「像 AI」當唯一理由改稿。
- 不為了讓數字好看而刪掉人類本來就常用的手法（比喻、設問、排比、被動）。
